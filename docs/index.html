Designed for Modern Linux Desktops

Engineered with Rust for near-zero memory footprint and zero CPU idle usage.

Wayland & X11 Native

Seamlessly integrates with GNOME Shell custom shortcuts via gsettings, bypassing Wayland background hotkey isolation restrictions.

SQLite Fast Storage

Local, encrypted SQLite database indexed for instant search. Auto-rotates and caps history at 500 entries.

Low CPU Footprint

SHA-256 content deduplication worker thread ensures clipboard polling consumes 0.0% CPU when idle.

Top-Bar System Tray

Integrated status indicator in the GNOME top bar with instant menu actions for quick access.
